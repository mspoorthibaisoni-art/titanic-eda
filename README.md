# Titanic Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.

The analysis uses statistical summaries and visualizations to understand the factors associated with passenger survival.

## Dataset

The Titanic dataset contains information about passengers, including:

- Passenger class
- Gender
- Age
- Fare
- Survival status
- Other passenger-related information

## EDA Performed

The following analyses were performed:

1. Basic information about the dataset
2. Survival distribution
3. Survival analysis by gender
4. Survival analysis by passenger class
5. Age distribution
6. Fare distribution
7. Correlation analysis using a heatmap
8. Survival analysis by gender and passenger class

## Key Insights

### 1. Survival Distribution
Survival was not evenly distributed among the passengers.

### 2. Gender and Survival
Survival rates differ between male and female passengers, making gender an important variable for analysis and modeling.

### 3. Passenger Class and Survival
Passenger class is associated with survival rate and can be useful as a predictive feature.

### 4. Age Distribution
Passengers had a wide range of ages. Age can provide useful information for understanding survival patterns.

### 5. Fare Distribution
Passenger fares varied considerably and provide additional information about passenger characteristics.

### 6. Gender and Passenger Class
The combination of gender and passenger class provides more detailed information about survival.

### 7. Correlation Analysis
The correlation heatmap helps identify relationships between numerical variables and can support future feature selection.
